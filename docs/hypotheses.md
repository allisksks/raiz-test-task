# Гипотезы о причинах ценовых различий

Ценовой сигнал отвечает на вопрос «что произошло». Движок гипотез (`src/market_map/hypotheses.py`) отвечает на вопрос **«за счёт чего конкурент может продавать дешевле?»**. Он запускается автоматически после сигналов. Вручную: `market-map generate-hypotheses`.

Гипотезы строятся для сигналов: «новый конкурент и изменение маржи», «новый конкурент», «снижение цены конкурента», «новый товар-заменитель». Хранятся в `core.hypothesis`, для Superset есть витрина `marts.hypotheses` с рангом гипотезы внутри сигнала.

## Как устроена гипотеза

У каждой гипотезы есть список **доводов**. У довода есть текст, вес, признак «подтвердился» и вид — **факт** или **оценка**.
- **Оценка гипотезы** — сумма весов подтвердившихся доводов, не больше 1.
- **Обоснование** — подтвердившиеся доводы через «;».
- У самой гипотезы всегда `provenance = hypothesis`: это вывод, а не факт, даже если все доводы фактические.

Если ни одна гипотеза не набрала 0,4, добавляется «Другие факторы: данных для уверенного вывода недостаточно».

| Гипотеза | Доводы (вес) |
|---|---|
| Прямые закупки у производителя | Схема поставок «прямые/с завода/от производителя» (0,35). Цена на те же товары ниже нашей закупочной более чем на 3% (0,35) или примерно равна ей (0,2). Продаёт те же товары, что и мы (0,15) |
| Большие объёмы закупок | Централизованные закупки (0,3). Работает в ≥3 регионах (0,2). Ассортимент ≥15 позиций (0,15). Цена около или ниже нашей закупочной (0,2) |
| Новая дистрибьюторская цепочка, меньше посредников | Юрлицо моложе года на момент выхода в регион (0,3). Дистрибьютор или оптовик (0,2). Прямые поставки (0,2). Недавно вышел в регион (0,15) |
| Региональный склад, дешёвая логистика | Склад в регионе по данным мониторинга (0,4). Наша цена в регионе выше средней по стране в том же канале на ≥2% (0,3, оценка) |
| Агрессивный выход на рынок | Только для новых конкурентов (0,3). Цена ниже нашей на ≥15% (0,3). Ниже нашей закупочной (0,15). Новое юрлицо (0,1) |
| Временное снижение цены (акция) | Цена вернулась в течение 6 недель (0,7). Во время снижения цена ниже нашей закупочной (0,15). Если с момента снижения прошло меньше 6 недель — «акцию нельзя исключить» (0,2, оценка) |
| Дешёвый аналог, другая структура затрат | Продаёт в основном аналоги (0,4). Схема «производство аналогов» (0,3). Сигнал о товаре-заменителе (0,2). Аналог дешевле нашей закупочной цены оригинала (0,15) |

Логика сравнения цен:
- **С нашей закупочной ценой сравниваются только идентичные товары.** Аналог конкурент покупает у другого производителя, поэтому «аналог дешевле нашей закупки» говорит о структуре затрат, а не о прямом контракте.
- **Если цена вернулась (акция),** низкая цена объясняется акцией и не считается доводом за выгодные закупочные условия.

## Ценовая архитектура

Для каждого сигнала строится разложение (`core.price_breakdown`, витрина `marts.price_breakdown`). Значения — медианы по товарам за период сигнала.

| Шаг | Компонент | Происхождение |
|---|---|---|
| 1 | Наша закупочная цена (себестоимость из 1С) | факт |
| 2 | Наша цена продажи | факт |
| 3 | Наша наценка | факт |
| 4 | Цена конкурента | факт |
| 5 | Разрыв с нашей ценой | факт |
| 6 | Цена конкурента к нашей закупочной (отрицательная — продаёт дешевле, чем мы покупаем) | факт |
| 7 | Закупочная цена конкурента при нашей наценке | оценка |
| 8 | Насколько дешевле конкурент должен закупать при нашей наценке | оценка |

| Сигнал | Ведущие гипотезы |

| S1 «СибСтройОпт», Новосибирск | Прямые закупки у производителя, новая дистрибьюторская цепочка, агрессивный выход — по 0,85. Его цена на те же товары на 18% ниже нашей закупочной: 326 ₽ против 402 ₽ |
| S6 «ГиперСтрой Федерал», Самара | Большие объёмы закупок федеральной сети (0,85), агрессивный выход (0,6) |
| S4 «КазаньСтройТорг», Казань | Временная акция (0,85): цена вернулась через 28 дней |

Региональный склад у «СибСтройОпт» набирает только 0,4. Склад есть, но наша цена в Новосибирске выше средней по стране всего на 1,4% — ниже порога 2%. Дорогой логистики, которую можно обойти, в данных не видно.
