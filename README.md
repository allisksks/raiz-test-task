# Market Map — интерактивная карта России

Инструмент оперативного мониторинга и диагностики рынка. На карте России видны клиенты, конкуренты, цены и их изменения. Система сама находит значимые изменения — новый конкурент, снижение цен, падение маржи — и предлагает гипотезы, почему это произошло. Факты, расчётные оценки и аналитические гипотезы разделены и в данных, и на дашборде.

Путь из ТЗ: **клиент → регион → номенклатура → конкурент → цена → изменение → причина → гипотеза**.

![Карта рынка](docs/img/market-map.png)

## Быстрый старт

Нужны Docker и Docker Compose.

```bash
cp .env.example .env                      # при необходимости поменяйте пароли
docker compose up -d --build --wait       # PostgreSQL + Superset с дашбордами
docker compose run --rm app migrate       # схема хранилища и справочники
docker compose run --rm app load-1c       # продажи, клиенты, план маржи (тестовая выгрузка 1С)
docker compose run --rm app load-prepared # конкуренты и цены (тестовая подготовленная база)
```

Откройте http://localhost:8088 (`admin` / `admin`) и выберите дашборд **«Карта рынка»** или **«Диагностика: сигнал → причина»**. Витрины, сигналы и гипотезы пересчитываются сами после каждой загрузки.

Остановить: `docker compose down`. Удалить вместе с данными: `docker compose down -v`.

## Сценарий демо (5 минут)

Тестовые данные синтетические, в них заложены шесть сценариев из ТЗ ([docs/test-data.md](docs/test-data.md)). Главный из них — пример из ТЗ: у клиента падает маржа, потому что в регионе появился конкурент с ценой на 25% ниже.

1. **«Карта рынка».**
   - На карте маржи Новосибирская область красная: маржа клиентов на 2,1 п.п. ниже плана.
   - На карте новых конкурентов выделены Новосибирск и Самара.
   - В ленте сигналов — 24 критичных.
2. **Лента сигналов.** Составной сигнал из ТЗ:
   > В регионе Новосибирская область появился новый конкурент ООО «СибСтройОпт» с ценой на 21% ниже цены клиента ООО «СибДистрибуция» по «Сухие смеси». Одновременно маржа клиента снизилась на 8,3 п.п. (с 9,1% до 0,8%)
3. **«Диагностика: сигнал → причина».** Она открывается сразу на этом регионе.
   - **Гипотезы «за счёт чего конкурент дешевле»:** прямые закупки у производителя, новая дистрибьюторская цепочка, агрессивный выход на рынок — по 0,85, у каждой есть доводы.
   - **Ценовая архитектура.** На те же товары конкурент продаёт по 326 ₽, а наша закупочная цена — 402 ₽. Это факт из 1С и мониторинга, а его закупочная цена — помеченная оценка.
   - **Графики.** С 06.07 появляется конкурент на −25…−30%, наша оценочная доля по сухим смесям падает с 44% до 28%, фактическая маржа уходит от плана.
4. **Другие сценарии** — выберите в фильтре «Регион»:
   - Самара: федеральная сеть с объёмами закупок;
   - Республика Татарстан: временная акция −20%, цена вернулась через 28 дней;
   - Свердловская область: дешёвый аналог;
   - Краснодарский край: конкурент поднял цены на 12%;
   - Москва: конкурент ушёл.
5. **Таблица «Источники данных»** внизу «Карты рынка»: когда загружался каждый источник и насколько он достоверен.

## Как устроено

```
 1С (OData или выгрузка) ──┐
                           ├─► staging ─► core ─► marts ─► Superset (карта, дашборды)
 Подготовленная база ──────┘    сырьё    модель   витрины
 (парсинг цен конкурентов)                 │
                                           └─► сигналы ─► гипотезы + ценовая архитектура
```

|---|---|---|
| Загрузка из 1С | `src/market_map/integrations/onec/` | [docs/integration-1c.md](docs/integration-1c.md) |
| Загрузка подготовленной базы, сопоставление товаров | `src/market_map/integrations/prepared/`, `matching.py` | [docs/integration-prepared-db.md](docs/integration-prepared-db.md) |
| Модель данных и витрины для BI | `src/market_map/migrations/` | [docs/marts.md](docs/marts.md) |
| Сигналы о рыночных изменениях | `src/market_map/signals.py` | [docs/signals.md](docs/signals.md) |

**Стек:** Python 3.12, PostgreSQL 16, Apache Superset 4.1, Docker Compose, GitHub Actions.

**Факт, оценка, гипотеза.** У каждого числа в хранилище есть `provenance`:
- `fact` — из источника (1С, мониторинг цен);
- `estimate` — расчёт (доли рынка, закупочная цена конкурента);
- `hypothesis` — вывод о причине.

У источников есть достоверность A/B/C, у каждой цены — источник.

## Команды

| Команда | Что делает |
|---|---|
| `market-map migrate` | Миграции схемы и справочники (85 регионов РФ, каналы) |
| `market-map load-1c [--path …] [--from YYYY-MM --to YYYY-MM]` | Загрузка из 1С: живая база по OData (`ONEC_ODATA_URL`) или файлы выгрузки |
| `market-map load-prepared [--path …]` | Загрузка подготовленной базы (`PREPARED_DB_URL`: SQLite или любая СУБД) |
| `market-map refresh-marts` / `detect-signals` / `generate-hypotheses` | Пересчёт вручную; после загрузок выполняется автоматически |
| `market-map generate-samples` | Пересоздать тестовые данные |
| `market-map check` | Проверка доступа к хранилищу |

В Docker: `docker compose run --rm app <команда>`. Короткие варианты — в `Makefile`.

## Разработка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
make lint     # ruff
make test     # pytest; тесты с БД идут в отдельной базе <POSTGRES_DB>_test и пропускаются без PostgreSQL
```

CI (GitHub Actions) выполняет три проверки:
- `lint`;
- `test` — pytest на PostgreSQL;
- `compose` — стенд с нуля: загрузки, доступ BI к витринам, импорт дашбордов.

Ветки: `main` (релизы) ← `dev` ← `feature/*`, правила — в [PLAN.md](PLAN.md#8-git-процесс). История изменений — [CHANGELOG.md](CHANGELOG.md).

## Ограничения и что дальше

- **Данные синтетические.** Форматы 1С и подготовленной базы — контракт для загрузчиков. Реальные данные подключаются через адаптеры, ориентиры для «Управления торговлей 11» — в [docs/integration-1c.md](docs/integration-1c.md).
- **Доли рынка — оценка** по ассортименту и цене, без масштаба бизнеса. Калибровать по ГИР БО и Росстату ([docs/data-sources.md](docs/data-sources.md)).
- **Фильтры раздела 9 ТЗ.** На дашборде есть регион, клиент, конкурент, группа товаров, товар, канал и период. Цена и «новые конкуренты» реализованы сортировкой таблиц и отдельными показателями, а не фильтрами. Таблицы позволяют спуститься до клиента и товара, но карта не проваливается в регион по клику: так ведёт себя Country Map в Superset.
- **Внешние источники** (ЕГРЮЛ, ЕИС «Закупки», ГИР БО, маркетплейсы) описаны в реестре с приоритетами подключения, но пока не подключены.
